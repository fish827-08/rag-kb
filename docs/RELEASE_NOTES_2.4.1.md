# kb v2.4.1 发布说明（2026-11-03）

v2.4.0 大表实测后的修复版本，聚焦表格问答准确性。

## 修复

- **多 sheet 消歧**：行首 `[表名]` 前缀解析为 `__sheet`；问题中出现表名时只答对应 sheet，
  多个表名互为子串时取最长匹配（「十五班」优先于「五班」）；未指定表名时每条答案带表名前缀。
- **聚合口径修正**：平均分排除学号 / 序号 / 已有总分列；问题明确问「总分」且表中已有总分列时
  直接读取该列，不再重复求和。
- **短数字防误命中**：分数 `50` 这类 2~3 位纯数字不再因子串出现在长数字（如 `1500`）中而被
  当成行定位键；4 位以上学号/编号仍可用于定位。

## 实测数据

- 15 sheet × 30 行 Excel（450 行）：解析 0.30s、入库 9.45s、表格问答 0.02s、检索 0.08s；
  重启后 450 条记录完整读回。
- 2000 行 CSV（超过 500 行自动聚合为 223 个多行块）：入库 14.28s，按姓名问单元格 0.02s 精准命中。
- 同名跨班场景：问「五班张芳的数学成绩」只返回五班一条；问「王艳的语文成绩」返回各班并带表名前缀。
