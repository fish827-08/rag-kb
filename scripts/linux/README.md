# Linux / macOS 一键启停脚本（预留）

本目录为 Linux/macOS 预留，计划提供：

- `start_kb.sh` — 后台启动（nohup + 日志上次）。
- `start_kb_console.sh` — 前台调试窗口。
- `stop_kb.sh` — 停止服务。

> Windows 用户请使用 `../windows/` 下的 `.bat` 脚本。
> This directory is reserved for Linux/macOS one-click scripts
> (not implemented yet). Windows users: use `../windows/`.
