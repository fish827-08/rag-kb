## 七、发现与残留

### 7.1 本轮已修复

| 级别 | 问题 | 处置 |
|---|---|---|
| 低 | MCP `serverInfo.version` 为空 | `MCPServer(version=kb.__version__)`；新增测试；E1 复验 `2.0.0` |
| 测试方法 | CLI 复用旧数据目录 + 仓库 `.env` 开启 dedup，导致二次运行 D2 被去重拦截 | 脚本每轮清理隔离目录并显式关闭治理开关；产品行为符合预期，未改产品代码 |

### 7.2 非阻断观察

1. **坏模型错误文本**：离线模式下底层异常仍显示 HuggingFace 连接失败。外层 503 已提供 `model` 与 `hint`，用户可据此修正配置；若后续要彻底改写原始错误，可在 embedder 层做错误归类。
2. **一键停止的作用域**：见第五节，适合单实例；并行测试请按 PID 停止。
3. **`kb.pid` 位置**：按服务进程当前工作目录写入。`start_kb.bat` 会切到仓库根，因此正常使用无影响；从其他目录手工 `python -m kb serve` 时 pid 文件会落在该目录。
4. **默认模型切换**：已有库会沿用 `kb_data/runtime.json` 记录的建库模型，不会被新默认值悄悄改维度；这是刻意的数据保护行为，已在 README / 设计文档说明。
