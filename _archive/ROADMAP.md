## 项目定位

这个项目有两个层面：

1. **主线（阶段0-3）：RAG + Agent 应用系统** — 系统学习 AI 应用开发全链路技术，产出扎实的、能写进简历的开源项目
2. **长期探索（不设期限）：Agent 认知引擎** — 专攻"记忆架构（A）+ 思考模式路由（C）"方向，作为个人技术深化的方向，不追求短期出成果

阶段0-3 是硬目标，必须完成。长期探索是软目标，有时间就推进，没有也不影响就业竞争力。

### 阶段 2：API 化 + 检索优化 + 工程化

**目标：** 把 CLI 工具变成一个完整的工程化项目——API 服务 + 检索调优 + 容器化部署 + 可观测性

这个阶段不只是"加个 API"，而是把项目从"能跑的 demo"提升到"能交付的工程"。内容分四个模块：

#### 2.1 FastAPI 接口化

| 任务 | 内容 | 就业价值 |
|---|---|---|
| REST API 设计 | POST /documents 导入、POST /ask 问答、GET /health 健康检查 | API 设计能力 |
| Pydantic 数据校验 | 请求/响应模型定义、输入校验 | FastAPI 核心技能 |
| 异步处理 | async/await，支持并发请求 | Python 异步编程必备 |
| 错误处理 | 统一异常处理、HTTP 状态码规范 | 工程规范 |
| API 文档 | FastAPI 自动生成 OpenAPI/Swagger 文档 | 开箱即用的文档能力 |

#### 2.2 检索优化

| 任务 | 内容 | 就业价值 |
|---|---|---|
| chunk 参数调优 | 系统性测试不同 chunk_size/overlap 的效果，记录对比数据 | RAG 调优是岗位核心技能 |
| 混合检索 | 向量检索 + BM25 关键词检索，两者结合提升召回 | RAG 进阶技能 |
| 重排序（rerank） | 用 cross-encoder 对检索结果重排，提升精度 | 简历亮点 |
| 多路召回 | 并行检索多个数据源，合并结果 | 工程能力 |
| 检索结果去重 | 避免重复内容干扰模型回答 | 细节处理 |

#### 2.3 工程化与部署

| 任务 | 内容 | 就业价值 |
|---|---|---|
| Docker 容器化 | Dockerfile + docker-compose，一键部署 | DevOps 基础加分 |
| 环境管理 | 开发/测试/生产环境分离，配置管理 | 工程规范 |
| 日志系统 | 结构化日志，请求追踪 | 可观测性基础 |
| CI/CD | GitHub Actions / Gitee Go 自动测试+部署 | DevOps 加分 |

#### 2.4 数据层增强

| 任务 | 内容 | 就业价值 |
|---|---|---|
| 文档管理 | 记录已导入文档列表、支持删除指定文档 | 产品完整度 |
| 增量更新 | 新文档追加不重建整个库 | 工程优化 |
| 元数据管理 | 文档来源、导入时间、标签等 | 数据管理能力 |

**预计时间：** 阶段1 完成后 5-6 周（内容增多，比原计划多 2 周）

**简历价值：** "RAG 系统 API 化，支持异步并发、混合检索+重排序、Docker 部署、CI/CD"

**学到的技术栈：**
- FastAPI + Pydantic（Python Web 框架，API 设计）
- async/await（Python 异步编程）
- 混合检索 + rerank（RAG 进阶技能）
- Docker + docker-compose（容器化部署）
- 结构化日志 + CI/CD（工程化）

**验收标准：**
- [ ] API 能被 Postman/curl 正常调用
- [ ] 有检索优化前后的效果对比数据
- [ ] `docker-compose up` 一键启动服务
- [ ] 有 CI 自动跑测试

### 阶段 3：Agent + 评估 + 产品化

**目标：** 从"问答工具"升级为"有记忆、能多轮对话、质量可量化的 AI 应用"

这个阶段是就业竞争力的核心——AI Agent 是当前最热的岗位方向。内容分三个模块：

#### 3.1 LangGraph Agent

| 任务 | 内容 | 就业价值 |
|---|---|---|
| LangGraph 状态图 | 用状态机管理多轮对话流程 | Agent 开发岗核心技能 |
| 多轮对话 | 支持上下文追问、"它指什么"等指代消解 | 产品完整度 |
| 工具调用 | Agent 能调用外部工具（搜索、计算、API） | Function Calling 是热点 |
| 流式输出 | SSE 流式返回，边生成边显示 | 用户体验提升 |

#### 3.2 记忆系统

| 任务 | 内容 | 就业价值 |
|---|---|---|
| 短期记忆 | 当前对话上下文管理、token 窗口管理 | Agent 记忆基础 |
| 长期记忆 | 对话历史持久化、用户偏好记忆 | 记忆系统设计 |
| 记忆检索 | 从历史记忆中检索相关信息辅助回答 | RAG 技能复用 |
| 记忆摘要 | 自动压缩长对话历史，避免 token 溢出 | 工程优化 |

**与长期方向的关系：** 这里的记忆系统是 A 方向（记忆架构）的入门起点。从这里开始接触"记忆怎么存、怎么找、怎么压缩"。

#### 3.3 质量评估与产品化

| 任务 | 内容 | 就业价值 |
|---|---|---|
| RAGAS 评估 | 4个维度量化检索质量（faithfulness/answer_relevancy/context_precision/context_recall） | 区分"能做"和"做得好" |
| A/B 测试框架 | 对比不同参数配置的效果 | 数据驱动优化 |
| 引用溯源 | 回答标注来源片段和置信度 | 可信 AI 加分项 |
| 前端界面 | 简单的 Web UI（可用 Gradio/Streamlit） | 演示能力 |
| 性能监控 | 响应时间、token 消耗、检索质量监控 | 可观测性 |

**预计时间：** 阶段2 完成后 5-6 周

**简历价值：** "AI Agent 应用开发：LangGraph 多轮对话 + 记忆系统 + RAGAS 质量评估 + 流式输出"

**学到的技术栈：**
- LangGraph（Agent 状态图编排）
- Function Calling / Tool Use（Agent 工具调用）
- 记忆系统设计（短期+长期+摘要）
- RAGAS（RAG 质量评估框架）
- SSE 流式输出
- Gradio/Streamlit（快速 UI）

**验收标准：**
- [ ] 支持多轮对话，能理解上下文追问
- [ ] 有长期记忆，跨会话能记住用户偏好
- [ ] RAGAS 评估报告，4个维度有数据
- [ ] 流式输出，回答逐字显示
- [ ] 有 Web UI 可演示

**方向：** 记忆架构（A）+ 思考模式路由（C）

这是研究型方向，个人开发者很难给出明确时间表。作为一个长期探索的目标，按兴趣和时间自由推进：

#### 探索路径

| 步骤 | 内容 | 性质 |

| 3. 小实验 | 在阶段3 的记忆系统上，尝试加遗忘机制或简单路由 | 实践验证 |
| 4. 找切入点 | 理解别人做了什么、没做什么，找到自己的差异化点 | 定方向 |
| 5. 深入做 | 选一个子方向打穿（记忆架构 或 路由器，不贪多） | 专攻 |

#### A+C 理想架构（参考，非短期目标）

```
用户提问
    ↓
┌─────────────────────────────────┐
│  C: 思考模式路由器                 │
│  判断该用哪种思考模式               │
│  - 快思考（直接答）                │
│  - 慢思考（检索后答）              │
│  - 深度思考（多步推理）            │
│  - 反思模式（回答后自检）          │
└──────────┬──────────────────────┘
           ↓
┌──────────┴──────────────────────┐
│  A: 记忆系统                      │
│  根据思考模式，提供不同的记忆支撑     │
│  - 工作记忆（当前对话上下文）       │
│  - 语义记忆（知识库检索）           │
│  - 情景记忆（历史经验复用）         │
│  - 遗忘机制（按重要度衰减）         │
└─────────────────────────────────┘
           ↓
        输出回答 + 置信度
```

**阶段3 是就业目标线。** 完成后即具备投 AI 应用开发岗的竞争力。长期探索是加分项，不是必选项。

### 技术栈与岗位对应

| 技术栈 | 对应岗位 | 在哪个阶段学到 |

| Python + LangChain + RAG | AI 应用开发 | 阶段1-2 |

### 关键认知

1. **阶段1 完成就可以开始试水投简历** — 感受市场要什么、面试问什么
2. **阶段3 完成可以正式投 AI 应用开发岗** — 有完整项目 + Agent 经验
3. **不追求"全部学完才跳"** — 边做边投，面试反馈反哺学习方向
4. **长期探索不影响就业** — 阶段3 完成就够用了，探索是个人兴趣
