# kb 产品手册（样例知识库文档）

kb 是一个本地优先的 RAG 知识库与 Agent 记忆服务。它把本地文档、网页、CSV/Excel
统一入库，提供向量与 BM25 混合检索；不配置大模型也能完成入库与检索。

## 嵌入模型

- 默认模型是 `BAAI/bge-small-zh-v1.5`，磁盘约 92MB，向量维度是 **512**。
- 可选模型 `BAAI/bge-base-zh-v1.5`，向量维度是 **768**。
- 可选模型 `BAAI/bge-m3`，磁盘约 2.2GB，向量维度是 **1024**，多语言能力更强。
- 已知模型的维度内置在代码里，表格行入库不需要为此加载模型。

## 模型迁移

v2.5.0 起支持在库中已有数据时切换嵌入模型：

1. 每个模型在每个作用域拥有独立的 Chroma collection；
2. 迁移在后台执行，迁移期间进入只读窗口：写入返回 409，读取继续；
3. 语义检索在只读窗口内临时降级为 BM25 关键词检索；
4. 全部作用域同步完成后才切换模型，失败会保留旧库并允许重试；
5. 旧模型的数据不会自动删除，需要在设置面板手动删除。

## 数据导入

- 文本：`.md`、`.txt`、`.rst` 直接读取；
- 文档：`.pdf`、`.docx`、`.html`、`.json` 等经过解析管道；
- 表格：`.csv`、`.xls`、`.xlsx` 逐行入库，支持多 sheet 按表名消歧。

## 端口与实例

默认端口 8000。同一个数据目录只允许一个长驻实例，换端口不能绕过单例锁。
需要并行运行时，请为每个实例设置不同的 `KB_DATA_DIR`。
